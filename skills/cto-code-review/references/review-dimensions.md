# 代码评审九维

| 维度 | 看什么 | blocker 示例 |
|---|---|---|
| 正确性 | 逻辑是否符合 AC | 主路径结果错误 |
| 边界 | 空、超长、并发、重复提交 | 未处理空值导致崩溃 |
| 错误处理 | 超时、重试、降级 | 异常被吞掉 |
| 数据 | 迁移、回滚、索引、事务 | 不可逆迁移无备份 |
| 接口契约 | 字段、错误码、版本兼容 | 破坏性改字段 |
| 安全 | 鉴权、注入、密钥、日志脱敏 | 越权访问 |
| 性能 | N+1、全表扫、无界队列 | 线性内存增长 |
| 可观测性 | 日志、指标、追踪 | 关键路径无错误日志 |
| 测试 | 新行为、失败路径、回归 | 只测 happy path |

## 规则

- blocker 必须阻断合并。
- major 可以合并但必须建跟进项。
- minor 不阻塞，不堆在评审里当工作量。

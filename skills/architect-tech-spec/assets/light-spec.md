# 轻方案（`xs` / `s`）

适用：行为改动唯一、无新契约、无取合的技术改动。上游需求卡首行 `级别：xs` 或 `s` 时使用。

## 模板

```markdown
## 改哪儿
<文件 / 函数 / 配置项，指向具体位置>

## 怎么改
<实现方式，一段话；有替代方案就写为什么不用>

## 回归点
1. <可执行的验证动作或命令>
2. <边界或异常场景的一条>

## 风险
<回滚方式或影响面；没有写「无，改动可逆」>

级别：xs
```

## 规则

- 全文 ≤300 字或半屏，超了说明该升到 `m`。
- 不写数据模型、接口契约、部署、观测章节。
- 回归点必须可执行，不写「测试通过」。
- 涉及不可逆改动（数据迁移、权限、发布流程）时停，升为 `m` 走完整方案。

# Harness 能力域

| 域 | 要验证什么 | 常见缺口 |
|---|---|---|
| Shell | 命令执行、管道、退出码 | 缺 shell、权限不足 |
| 文件系统 | 读写、移动、权限、大文件 | 只读挂载、路径映射错 |
| 包管理 | 安装、锁文件、私有源 | 无网络、凭证缺失 |
| 语言运行时 | 版本、编译、依赖 | 版本过低、多版本冲突 |
| 版本控制 | clone、branch、commit、push | 无 ssh、无 token |
| 测试 | 测试框架、覆盖率、浏览器 | 缺原生依赖、无头浏览器 |
| 检索 | 全文搜索、代码索引 | 无 rg、索引过期 |
| 编辑器 | 读写、格式化、LSP | 无写权限 |
| 浏览器 | 打开、点击、截图 | 未安装、无法连显示 |
| 容器 | 构建、运行、挂载 | 无 docker、无权限 |

## 验证原则

- 每个域至少一条真实命令 + 退出码。
- 版本写在报告里，不只写「可用」。
- 权限单独验证：写、网络、凭据。
- 失败路径也要验证：命令不存在时是否可诊断。

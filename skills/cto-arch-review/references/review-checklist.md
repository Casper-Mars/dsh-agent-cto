# 评审八维清单

| 维度 | 要问的问题 | 不合格信号 |
|---|---|---|
| 目标与约束 | 目标可判定吗？约束真实吗？ | 目标写成「更好用」 |
| 模块边界 | 职责单一吗？依赖方向清楚吗？ | 循环依赖、共享数据库 |
| 数据 | 模型、约束、迁移、回滚齐全吗？ | 只写表名不写字段 |
| 接口 | 鉴权、错误码、幂等、限流齐全吗？ | 只写 happy path |
| 流程 | 异常、重试、补偿、并发处理了吗？ | 只有主路径 |
| 部署 | 顺序、灰度、回滚、配置齐全吗？ | 无回滚 |
| 观测 | 日志、指标、告警、追踪齐全吗？ | 只写「加日志」 |
| 安全与成本 | 权限、数据分级、容量与费用评估了吗？ | 无边界 |

## 结论规则

- 任一 blocker → 驳回。
- 只有 major/minor 且可复核 → 有条件通过。
- 全部通过且残余风险可接受 → 通过。

# 技术债分类

| 类型 | 例子 | 典型偿还方式 |
|---|---|---|
| 架构债 | 模块边界混乱、共享数据库 | 隔离、抽象层、逐步迁移 |
| 代码债 | 重复实现、超长函数 | 重构、提取、删代码 |
| 测试债 | 关键路径无测试 | 补特征测试、回归集 |
| 依赖债 | 版本过期、EOL | 升级、替换、隔离 |
| 数据债 | 无 schema、口径不一 | 建模、清洗、约束 |
| 运维债 | 手工部署、无监控 | 自动化、可观测性 |
| 文档债 | 运行手册缺失 | 补最小可用文档 |

## 偿还策略

- **顺手还**：改动同一模块时，成本 < 20%。
- **单独排期**：影响交付或故障率高。
- **替换**：依赖 EOL 或锁定严重。
- **隔离**：短期不能还，限制影响面。
- **接受**：利息低于偿还成本，写理由并监控。

# 安全评审清单

## 数据分级

| 级别 | 例子 | 要求 |
|---|---|---|
| L1 公开 | 文档、公告 | 完整性 |
| L2 内部 | 日志、指标 | 访问控制 |
| L3 敏感 | 用户信息、合同 | 加密、审计、最小权限 |
| L4 高危 | 凭据、支付、密钥 | 硬件/托管密钥、双人复核 |

## 七类控制

1. 认证：谁能证明身份；会话与令牌生命周期。
2. 授权：谁能对什么做什么；默认拒绝。
3. 输入：校验、转义、大小限制、文件类型。
4. 加密：传输、存储、密钥轮换。
5. 审计：谁在何时做了什么；不可篡改。
6. 限流：防滥用、防枚举、防撞库。
7. 隔离：租户、环境、网络、进程。

## 高风险信号

- 自定义加密算法。
- 权限判断散落在业务代码。
- 日志打印令牌或完整身份证号。
- 管理接口暴露在公网。
- 依赖锁定在 EOL 版本。
- 数据导出无审批与审计。

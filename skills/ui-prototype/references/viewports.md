# 视口与状态约定

| 视口 | 尺寸 | 用途 |
|---|---|---|
| desktop | 1440 × 900 | 主验收尺寸 |
| tablet | 1024 × 768 | 断点验证 |
| mobile | 390 × 844 | 响应式验证 |

| 状态 | 必做 | 说明 |
|---|---|---|
| default | 是 | 常态数据 |
| empty | 是 | 空态必须有文案与下一步动作 |
| loading | 是 | 骨架屏，不用裸转圈 |
| error | 是 | 错误原因 + 重试 |
| long-list | 列表页 | 30 条以上，验证滚动与表头 |

命名：`<screen>__<viewport>__<theme>__<state>.png`
